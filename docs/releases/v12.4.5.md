# Not-Noop v12.4.5

## Skip the next alarm

The phone smart alarm and the strap alarm each have a **Skip next alarm** button (shown with the date it
skips). It passes over that one morning and leaves the alarm switched on; the day after, it rings as usual.
**Undo skip** brings the morning back. Changing that alarm's time, days or window clears the skip.

- The countdown and the alarm times on the screen follow the skip, so they always show the alarm that
  will actually ring.
- "Buzz WHOOP 4" follows the phone alarm's skip.
- The strap keeps its own copy of the strap alarm, so it hears about a skip only while connected. If it
  is not connected, the screen says so: it may still buzz that morning until it reconnects.

Requested upstream in ryanbr/noop#1611. Multiple separate alarms are not part of this release.

## Fixes

- **Health Connect sync on Android 8 to 13.** Sync used a date call that only exists on Android 14, so it
  crashed on older phones (reported upstream in ryanbr/noop#2789). The release build now refuses any call
  newer than the app's minimum Android version.
- **Back up to a single file.** Some storage apps, such as Proton Drive, cannot give an app a folder, so
  automatic backup had nowhere to go (reported upstream in ryanbr/noop#2868). In Backup you can now choose
  one file instead of a folder. Each backup replaces that file in place and is read back to check it; the
  file is never deleted, and if a backup cannot be written the old one is left as it was. Keeping several
  backups still needs a folder.

Everything else is unchanged from 12.4.4.
