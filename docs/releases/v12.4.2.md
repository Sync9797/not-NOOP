# Not-Noop v12.4.2

## Calls ring on a WHOOP 4.0

Thanks to the vibration preset experiment, we now know a WHOOP 4.0 has three built-in vibration
patterns: one long buzz, a long ringing run, and the pairs of short buzzes NOOP has used for
everything.

- **Incoming calls now use the ringing run** ("Ring" under Notifications › Calls). It plays once per
  call. The strap cannot stop a pattern early, so it would keep buzzing after you answer if it
  repeated. If you prefer the old call buzz, pick Single, Double, Triple or Long there.
- **Notifications are unchanged:** one round of the short-buzz pattern.
- A WHOOP 5.0/MG does not have the ringing pattern, so calls there keep the Long buzz.

## Test Centre

- The vibration presets experiment now offers only patterns 0, 1 and 2, the three a WHOOP 4.0 has, and
  drops the Stop button (the strap refuses it).

Everything else is unchanged from 12.4.1.
