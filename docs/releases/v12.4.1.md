# Not-Noop v12.4.1

## Vibration presets experiment (WHOOP 4.0)

Every buzz NOOP sends to a WHOOP 4.0 uses one built-in pattern (the alarm buzz), which is why
notifications, calls, Live Session nudges and tap-for-time all feel like the same triple vibration.
The strap has other patterns, but nobody has mapped which number feels like what.

**Settings › Test Centre › Vibration presets (WHOOP 4.0)**:

1. Tap **Read pattern list** once (the strap's answer goes into the strap log).
2. Tap a number (0 to 15) to feel that pattern once.
3. Tap what you felt: nothing, one short, two, three, long, or a different pattern.
4. Your results show in the card and are written to the strap log. Share them with Settings › Support ›
   Report a bug.

It only moves the strap's vibration motor; nothing on the strap is changed or stored. **Stop buzz**
ends a long pattern early. If the results show gentler patterns, a later update can use them for
notifications and nudges.

Everything else is unchanged from 12.4.0.
