# Not-Noop v12.3.3

Two small navigation changes.

- **Icons-only sidebar on tablets and foldables.** The side navigation on wide screens now shows only
  icons, with the screen you are on in a soft accent circle, and is narrower. Screen readers still read
  each tab's name. The phone bottom bar and the half-folded button pad keep their labels.
- **Tab names fit in every language.** With the Workouts tab added there are six tabs, and some
  translations were cut off on phones. The bar now uses shorter names where needed (for example
  "Progreso" and "Coach" in Spanish, "Jour" and "Suivi" in French); screen titles keep the full words.

Everything else is unchanged from 12.3.2.
