# Not-Noop v12.4.3

## Vibrations on the WHOOP 4.0

- **One buzz per notification.** Android tells NOOP about a notification every time an app posts *or
  updates* it, and many messaging apps update a notification a moment after posting it. NOOP used to buzz
  for each one, so a single message could send two or three buzzes a second apart. They overlapped on the
  strap into a jumbled "triple" buzz, whatever pattern you had picked. Now each notification buzzes once,
  and buzzes from several apps at the same moment become one tap.
- **Calls are back to the Long buzz.** The ringing pattern tried in 12.4.2 felt wrong on real calls, so
  it is removed. If you had picked it, calls go back to Long.
- Every buzz decision is now written to the strap log, so if a vibration still feels wrong, Settings ›
  Support › Report a bug shows exactly what was sent.

## Foldables

- **No Today button in book mode.** On a half-open foldable Today is always on screen, so the sidebar
  shows only Trends, Sleep, Workouts, Coach and More, plus Swap sides.

Everything else is unchanged from 12.4.2.
