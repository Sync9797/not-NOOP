# Not-Noop v12.4.4

## Clearer workout cues on the WHOOP 4.0

Some cues were built for a strap that can do short taps: they sent several buzz commands a fraction of a
second apart. A WHOOP 4.0 plays a whole pattern for every command, so those commands piled up into one
blur. On a WHOOP 4.0 each cue is now a single, distinct vibration:

- **Live Session "push a bit more":** one round of short buzzes (was two commands 0.65 s apart).
- **Live Session "ease off":** one long buzz (was three commands about a second apart). The two can no
  longer be confused.
- **Intervals:** the 3-2-1 countdown buzzes are dropped. They came once a second, and the last landed on
  top of the phase change. The buzz into rest, into work and at the end stay.

A WHOOP 5.0/MG is unchanged. Breathe was checked and was already fine.

Everything else is unchanged from 12.4.3.
